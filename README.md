##  Overview

Wrong-way driving (WWD) on highways and urban roads is a primary contributor to severe traffic fatalities. This system addresses the issue by integrating **deep learning detection (YOLOv8)** with **robust spatial tracking (ByteTrack)** and **Self-Calibrating Anomaly Detection**.

Rather than relying purely on rigid tripwires, the pipeline dynamically computes vector movement angles and dot products relative to established lane flows. The result is an adaptive, high-precision monitoring system paired with a matte-graphite **Security Operations Center (SOC)** dashboard.

```mermaid
    F --> I[ SOC Terminal Dashboard]
    H --> I
```

### 🔍 Pipeline Details
1. **Frame Ingestion:** Reads frames via OpenCV video capture streams.
2. **Detection & Tracking:** Bounding boxes are generated by YOLOv8 and assigned unique, persistent track IDs by ByteTrack.
3. **Trajectory Accumulation:** Historical centroids are appended to track queues to construct movement vectors ($\Delta x, \Delta y$).
4. **Vector Analysis:** Vector dot-products measure angular alignment against permitted flow directions.
5. **Event Emission:** Violations trigger the `SnapshotManager` for image cropping and `ViolationLogger` for CSV writes.

## 🚀 Quick Start

**1. Clone the repository and navigate to the root directory:**
```bash
git clone [https://github.com/](https://github.com/)<your-username>/Wrong-Direction-Vehicle-Detection.git
cd Wrong-Direction-Vehicle-Detection

```
**2. Create and activate a virtual environment:**
```bash
# Linux/macOS
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate
```
**3. Install the required Python packages:**
```bash
pip install --upgrade pip
pip install -r requirements.txt
```
**4. Start the Streamlit application:**
```bash
streamlit run dashboard/app.py
```
*Open your browser and navigate to `http://localhost:8501`.*

## 🔀 Configuration & Road Layouts

The system supports adaptive direction analysis. The `DirectionAnalyzer` handles various traffic configurations:

*   **Two-Way Traffic (Left-Hand / India & UK):** Left lane flows UP, Right lane flows DOWN.
*   **Two-Way Traffic (Right-Hand / US & EU):** Left lane flows DOWN, Right lane flows UP.
*   **One-Way Highways:** All lanes enforced in a single uniform direction.
*   **Self-Calibrating Anomaly Mode:** Automatically observes initial vehicle trajectories to establish baseline flow without manual configuration.
